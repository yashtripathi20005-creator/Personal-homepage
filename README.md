# Personal Portfolio Website

A clean, modern personal portfolio and contact page built with Python (Flask) and Bootstrap 5.

## Features

- **Homepage**: Profile bio, social links, featured projects, and tech stack.
- **Contact Form**: Users can send messages; messages are stored in a JSON file.
- **Messages Dashboard**: Simple view to see all received messages.
- **Responsive Design**: Works on all screen sizes.
- **Flash Messages**: User feedback for form submission.
